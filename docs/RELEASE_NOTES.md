# Wonkys Wash v1.4.0-beta

A Qbox laundromat where washing is only the first stage: rent a private washer/dryer pair, wash dirty cash, collect a wet-money bundle and dry it before receiving clean cash.

Includes the branded inventory tablet, NPC rental desk, persistent placements/timers, animated Bzzz washer integration, bag handling, configurable fees, server checks and mocked tests.

**Required external downloads:**
- [Mrs. BzZz Money pack](https://bzzz.tebex.io/package/7390529)
- [gtaDPS Abandoned Laundromat MLO](https://www.gta5-mods.com/maps/abandoned-laundromat-interior-singleplayer-fivem-gtadps)
- Qbox, ox_lib, ox_target, ox_inventory and oxmysql.

External props/maps are not bundled. Follow README installation, item and placement steps. Keep the installed resource name Wonkys_MoneyWash.

**Beta limits:** latest money-bag alignment and multiplayer rental scenarios need live testing. Temporary bags are local cosmetic props. Interrupted cross-system financial transfers require staff reconciliation; they are not blindly replayed. Count-based black_money is supported; metadata-worth markedbills needs an adapter.
