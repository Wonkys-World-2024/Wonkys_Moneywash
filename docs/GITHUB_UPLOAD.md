# Upload this source edition

1. Extract the ZIP on your PC.
2. Create a repository named **Wonkys_MoneyWash**. Suggested description: `Two-stage Qbox money washing with animated Bzzz washers, dryer gameplay and a branded rental tablet.`
3. Upload the CONTENTS of the extracted Wonkys_MoneyWash folder to the repository root. README.md and fxmanifest.lua should appear at root, not inside another nested resource folder. Include .github, .gitignore and .gitattributes; GitHub Desktop or git is the easiest way to include these dotfiles.
4. Do not upload your server's live resource folder, SQL dumps, Bzzz pack, laundry MLO or previous full installation ZIPs.
5. Keep the supplied MIT code licence and the separate artwork notice. This edition deliberately gives the code MIT permissions; the Wonkys branding is treated separately in ASSETS.md.
6. Enable GitHub private vulnerability reporting in repository settings if available. Review Actions results after upload.
7. Create a release tag **v1.4.0-beta** and mark it as a **pre-release**. Copy the release text from docs/RELEASE_NOTES.md. Attach this source ZIP if desired; it contains no external props/map assets.
8. Suggested repository topics: `fivem`, `qbox`, `qbx-core`, `ox-lib`, `ox-target`, `ox-inventory`, `moneywash`, `lua`.

No GitHub username, repository URL, deployment token, Discord invite or server join address has been guessed or inserted. Add your support/community links later if you want them public.
